01 / The idea

Surface filters read the words. This reads the state that decides them

Builds on Arditi et al.'s finding that a single direction in residual-stream activation space causally controls refusal across open chat models (NeurIPS 2024, arXiv:2406.11717). A keyword filter or a perplexity check only ever sees a prompt's wording, so disguising a harmful request as fiction or roleplay is enough to slip past them. An activation-based detector instead reads whatever internal state the model itself uses to decide “this is harmful”, the disguise never has to change what the request actually means.

01

Dense-direction detector

The difference of means between harmful and harmless activations, at the layer where it separates best. A new prompt is classified by projecting its activation onto this direction and thresholding against a value calibrated on held-out data.

02

SAE-feature detector

Where the dense direction finds one linear axis, this asks which specific sparse, interpretable features out of tens of thousands per layer, are causally responsible for refusal, using each model's own pretrained sparse autoencoder.

03

LLM-judge baseline

A 70B model (Llama-3.3, via Groq) prompted as a text-only classifier is a genuinely strong opponent, not a keyword-list strawman, to make the “activations beat surface text” claim mean something.

02 / What it found

Six models, real adversarial attacks, and a paired test behind every claim

0.91–0.99

AUROC across all 6 models

Both activation-based detectors crush the surface baselines on clean prompts, keyword filtering sits at ~0.60, perplexity filtering at ~0.52, essentially chance.

p = 0.0041

Dense-direction vs. a 70B judge

Tested on 3 models against Llama-3.3-70B reading the same prompts as text: activation-based ranking wins every time, significantly (DeLong p = 0.0041 / 0.0015 / 0.0053).

Q = 44.55

PAIR-paraphrase robustness spread

Real published jailbreak attacks (JailbreakBench's PAIR and GCG), not synthetic ones. Cochran's Q across all 6 models confirms the spread is real, not noise (p < 1e-6).
